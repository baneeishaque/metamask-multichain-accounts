# Snapchat Spotlight

A 35-second vertical script for Spotlight. Fast cuts, captions burned in (Spotlight is watched
muted), no logo at the start — hook first, brand last.

***

## "12 networks, 4 addresses, 1 phrase" — 35 seconds

| Time    | Visual                                                        | On-screen text                                  | Voice-over                                                                 |
| ------- | ------------------------------------------------------------- | ----------------------------------------------- | -------------------------------------------------------------------------- |
| 0:00–03 | Wallet account list scrolling fast through network names      | "12 networks…"                                  | Your wallet shows twelve networks.                                         |
| 0:03–06 | Same list collapsing into four dots                           | "…but only 4 addresses"                         | But only four addresses actually exist.                                    |
| 0:06–11 | Seed icon splitting into two tree trunks labelled secp256k1 / ed25519 | "1 seed → 2 curves"                      | One recovery phrase becomes one seed, and that seed grows two separate key trees. |
| 0:11–17 | Four monospace paths typing in, one per branch                | "4 paths → 4 keys"                              | Four paths, four keys: EVM, Bitcoin, Solana, TRON.                          |
| 0:17–23 | One key with nine chain badges orbiting                       | "9 EVM networks = 1 key"                        | The nine EVM networks share one key — address derivation never asks which chain. |
| 0:23–28 | Nine balance cards, each labelled with its own gas token      | "Same address ≠ same balance"                   | Same address everywhere. Separate balances everywhere.                     |
| 0:28–32 | Three panels: lock / paper / key                              | "Password ≠ phrase ≠ key"                       | Your password opens the vault. The phrase restores everything.             |
| 0:32–35 | Terminal: `npm run derive` → four accounts                    | "Verify it yourself → link in bio"              | And you can verify every step yourself. Link in bio.                       |

**Caption:**

12 networks → 4 accounts → 4 keys ← 1 phrase. The wallet design decision nobody explains. 🔑

`#web3 #metamask #crypto #blockchain #techtok #learnonSnap`

## Notes for posting

- Keep total runtime under 40s; Spotlight rewards completion rate over length.
- Burn captions at 80% width, centred, with a dark scrim — the paths and network names must be
  readable on a phone at arm's length.
- Reuse the Reel edit's VO track if the timing is close; do not reuse Instagram-format
  captions (they are too long for Spotlight).
